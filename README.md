# Python Practice Tasks

This project contains a set of beginner-friendly Python exercises focused on core programming concepts such as functions, recursion, lambdas, and list operations.

## Project Contents

- Task1.py - Basic function for applying a discount to a price
- Task2.py - Recursive factorial function
- Task3.py - Lambda-based GST calculator
- Task4.py - Using map() to apply GST to a list of prices
- Task5.py - Using filter() to filter prices by condition
- Task6.py - Combined function using map() and filter()
- Task7.py - Menu-driven program to manage a list of prices

## Learning Objectives

- Practice writing reusable Python functions
- Understand default parameters and validation logic
- Use recursion to solve mathematical problems
- Work with lambda functions
- Apply map() and filter() for list transformations
- Build a simple interactive menu-driven application

## How to Run

From the project folder, run any task file using Python:

```bash
python Task1.py
python Task2.py
python Task3.py
python Task4.py
python Task5.py
python Task6.py
python Task7.py
```

## Example Output

Each task prints sample results to demonstrate the logic, such as:

- discounted prices
- factorial values
- GST calculations
- filtered and mapped price lists
- average, minimum, and maximum prices from user input

## Notes

These scripts are intended for learning and practice. They demonstrate simple Python logic in a clear, beginner-friendly way.
